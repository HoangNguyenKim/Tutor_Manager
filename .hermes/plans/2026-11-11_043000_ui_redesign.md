# Tutor_Manager UI Redesign & Enhancement Plan

> **For Hermes:** Use this plan to guide the redesign of the Tutor_Manager frontend Dashboard and UI components to be clean, professional, metric-rich, and visually appealing.

**Goal:** Redesign and enhance the Tutor_Manager dashboard and UI components to display comprehensive metrics (teaching sessions, prep status, estimated revenue) and a modern card-based schedule layout for today's shifts, styled with a polished color palette.

**Architecture:** Update the frontend components (`DashboardPage.tsx`, layout, and cards) in `apps/frontend/src` with Tailwind CSS classes, improved typography, spacing, soft shadows, badges, and status indicators.

**Tech Stack:** React, TypeScript, Tailwind CSS, Lucide icons (or existing icon system), TanStack React Query.

---

## Proposed Approach & Design System
- **Color Palette:** Slate/Neutral neutral grays combined with vibrant indigo/blue primary accents, emerald for revenue/success, and soft rose/amber highlights for shifts/warnings.
- **Metrics Grid:** Top row with 3 professional summary cards:
  1. Total Teaching Sessions (with period comparison).
  2. Prepared Lessons progress (`X / Y` ratio with visual progress bar).
  3. Estimated Revenue (formatted currency, trend indicator).
- **Schedule Section ("Today's Shifts"):**
  - Modern timeline/card list for today's shifts.
  - Highlighted active shift with clear time badges, subject tags, student names, and address details.
  - Quick action buttons (Check, Direct, Prep).
