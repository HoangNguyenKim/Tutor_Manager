# ADR-0006: Prisma + better-sqlite3 for SQLite persistence

- Status: accepted
- Date: 2026-10-08

## Context

Need typed SQLite access with migrations, FK enforcement, and transactions in the packaged Electron app. `better-sqlite3@13` ships no Windows prebuilt binary (falls back to `node-gyp`, which fails without a VS toolchain).

## Decision

Pin `prisma@7.10.0` + `@prisma/client@7.10.0` + `@prisma/adapter-better-sqlite3@7.10.0` with `better-sqlite3@12.11.1` (has Windows prebuilds, satisfies the adapter's `^12.6.0` range). Migration SQL is generated by `prisma migrate dev`; a small `better-sqlite3` runner applies `migration.sql` files at boot (tracked in `schema_migrations`) so packaged apps migrate without the schema engine.

## Consequences

No native build tools required on Windows. Revisit `better-sqlite3@13+` when prebuilds exist.
